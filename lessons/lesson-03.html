第 03 课 · Week 1

普通后端基础：API、Server、Database、Auth、Storage、Queue、Logs

掌握普通后端系统的基本组成，作为理解 AI 后端增量复杂度的参照系。

后端基础API数据库

课程目标

掌握普通后端系统的基本组成，作为理解 AI 后端增量复杂度的参照系。

1. 知识树定位

这一课属于：

text
AI 应用工程
└─ 应用后端层
   ├─ API
   ├─ Server
   ├─ Database
   ├─ Auth
   ├─ Storage
   ├─ Queue
   ├─ Cache
   ├─ Logs
   ├─ Environment Variables
   └─ Deployment

这一课解决的问题是：

在学 AI 后端之前，先知道普通后端由哪些基础能力组成。

2. 后端的一句话定义

前端是用户看到和操作的部分。 后端是用户看不见，但真正处理规则、数据和执行动作的系统。

一句话：

text
后端 = 接收请求、处理逻辑、读写数据、调用服务、返回结果的系统

3. API 是什么？

API 可以理解为前端和后端之间的“标准沟通入口”。

例如用户点击“发送消息”：

text
前端不能直接操作数据库
前端也不能直接随便调服务器内部逻辑
前端只能通过 API 告诉后端：我要发消息

API 可能长这样：

text
POST /api/chat
GET /api/user/profile
POST /api/upload-report

需要记住：

text
API = 前端调用后端能力的标准入口

4. Server 是什么？

Server 可以理解为“运行后端程序的地方”。

它可能是：

text
一台云服务器
一个 serverless function
一个容器
一个本地开发服务

无需先学部署细节，只要知道：

text
Server = 后端代码运行并等待请求的地方

5. Database 是什么？

Database 是长期存数据的地方。

AI App 里常见的数据包括：

text
用户资料
会话
消息
记忆
报告文件记录
工具调用结果
模型调用日志
评测样本

需要记住：

text
Database = 结构化、可查询、长期保存的数据系统

注意：数据库并非文件夹。 数据库更像一套可查询的账本。

6. Auth 是什么？

Auth 是身份认证和权限控制。

它要回答：

text
你是谁？
你有没有登录？
你能不能访问这个数据？
你能不能执行这个动作？

例如：

text
用户 A 不能看到用户 B 的对话记录
用户未登录不能查看个人空间
普通用户不能访问后台管理接口

需要记住：

text
Auth = 确认身份 + 控制权限

7. Storage 是什么？

Storage 是存文件的地方。

数据库适合存结构化数据。 文件存储适合存：

text
图片
PDF
音频
视频
检查报告原图
导出文件

AI App 常常会有：

text
用户上传图片
语音录音
检查报告
生成的分享图
导出的 PDF

这些一般不会直接塞进普通数据库，核心是放到对象存储里。

需要记住：

text
Storage = 存大文件和非结构化文件

8. Queue 是什么？

Queue 是任务队列。

有些任务不适合用户一直等。

例如：

text
OCR 识别报告
生成长总结
批量处理文件
定时回访
发送通知
异步评测

用户点了上传报告，系统可以先返回：

text
已收到，正在处理

后端再把任务放入 Queue 慢慢处理。

需要记住：

text
Queue = 把耗时任务排队异步处理

9. Cache 是什么？

Cache 是缓存。

它用于加速经常被访问的数据。

例如：

text
用户阶段信息
常用配置
热门知识片段
模型路由配置
短期会话状态

可以先粗略理解：

text
Cache = 临时快速存取层

10. Logs 是什么？

Logs 是日志。

普通产品需要日志。 AI 产品更需要日志。

因为 AI 产品要知道：

text
用户说了什么
系统判断成什么任务
用了哪个模型
拼了哪些上下文
有没有读记忆
有没有查知识库
有没有调工具
模型输出是什么
有没有安全拦截
耗时多少
成本多少
有没有报错

需要记住：

text
Logs = 系统运行留下的记录

AI 产品如果没有日志，就很难评测、复盘和优化。

11. Environment Variables 是什么？

Environment Variables，环境变量。

它通常用于存敏感配置和环境配置，例如：

text
OPENAI_API_KEY
DATABASE_URL
JWT_SECRET
STORAGE_BUCKET

不要把 API Key 直接写在代码里。

需要记住：

text
环境变量 = 不直接写死在代码里的配置和密钥

12. Deployment 是什么？

Deployment 是部署。

也就是把本地能跑的代码，放到线上让真实用户访问。

它涉及：

text
服务器
域名
数据库
环境变量
日志
监控
回滚
安全
成本

需要记住：

text
Deployment = 把系统从本地开发状态变成线上可访问服务

13. 一次普通后端请求怎么跑？

用户点击“保存资料”：

mermaid
flowchart LR
  A[用户点击保存] --> B[前端]
  B --> C[POST /api/profile]
  C --> D[后端 Server]
  D --> E[Auth 检查用户身份]
  E --> F[校验请求数据]
  F --> G[写入 Database]
  G --> H[写 Logs]
  H --> I[返回成功]
  I --> B

14. 一次 AI 后端请求怎么多出来？

用户发送一句话给 AI：

mermaid
flowchart LR
  A[用户发送消息] --> B[前端]
  B --> C[POST /api/chat]
  C --> D[后端 Server]
  D --> E[Auth]
  E --> F[读取 Database 用户状态]
  F --> G[Harness 判断任务]
  G --> H[Context Assembly]
  H --> I[LLM API]
  I --> J[Guardrails]
  J --> K[写 Messages / Logs / Trace]
  K --> L[返回前端]

对比普通后端，AI 后端多了：

text
Harness
Context Assembly
LLM API
Guardrails
Trace
Memory Policy
Eval Data

15. 少量代码：普通 API 长什么样

ts
app.post("/api/profile", async (req, res) => {
  const userId = req.user.id
  const profile = req.body
  await database.user.update({
    where: { id: userId },
    data: profile
  })
  res.json({ success: true })
})

只需看懂：

text
/api/profile          = 接口地址
req.user.id           = 当前用户
req.body              = 前端传来的资料
database.user.update  = 更新数据库
res.json              = 返回结果

16. 少量代码：AI API 多了什么

ts
app.post("/api/chat", async (req, res) => {
  const userId = req.user.id
  const message = req.body.message
  const userState = await database.user.findById(userId)
  const context = await buildContext(userState, message)
  const answer = await callModel({
    message,
    context
  })
  await database.messages.create({
    userId,
    message,
    answer
  })
  await logModelCall({
    userId,
    message,
    context,
    answer
  })
  res.json({ answer })
})

AI API 比普通 API 多了：

text
读取用户状态
组装上下文
调用模型
记录模型调用日志
可能写入记忆
可能触发评测

17. 实战判断

后续看一个后端方案，要先问：

text
1. API 分哪些？
2. 数据存在哪里？
3. 用户身份怎么确认？
4. 文件怎么存？
5. 耗时任务怎么处理？
6. 日志记录什么？
7. 模型调用日志和普通业务日志是否分开？
8. 出错后怎么排查？

AI 项目还要继续问：

text
9. 上下文怎么组装？
10. 模型调用前后有没有安全检查？
11. 记忆什么时候写？
12. 工具调用有没有权限控制？
13. Trace 能不能复盘一次完整 AI 运行？
