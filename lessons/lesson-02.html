第 02 课 · Week 1

基础开发词典：JS、TS、Node、React、Python、npm

用工程位置理解常见开发名词，为后续阅读项目目录和代码片段建立基础。

开发常识项目结构工具链

课程目标

用工程位置理解常见开发名词，为后续阅读项目目录和代码片段建立基础。

1. 知识树定位

这一课属于：

text
AI 应用工程
└─ 基础开发层
   ├─ 前端
   ├─ 后端
   ├─ 编程语言
   ├─ 运行环境
   ├─ 框架
   ├─ 依赖管理
   └─ 代码协作

这一课解决的问题是：

无需马上写代码，但必须知道这些词在工程系统里分别处于什么位置。

2. 先建立一个大比喻

把一个 App 想成一家餐厅。

软件概念餐厅类比
前端餐厅大厅、菜单、服务员和客人看到的界面
后端后厨、订单系统、库存系统
API服务员把客人需求传给后厨的标准话术
数据库仓库和账本
模型 API外部专家顾问
React设计大厅和菜单的组件化方式
Node.js让 JavaScript 可以在后厨跑起来的环境
Python另一种后厨语言，AI 工程常用
npm原料和工具采购系统
package.json餐厅工具清单和启动说明
GitHub代码仓库和协作记录

3. JavaScript 是什么？

JavaScript，简称 JS。

最初主要用于网页交互。

例如：

text
点击按钮
弹出窗口
切换页面状态
提交表单
展示动画

现在 JavaScript 不只在浏览器里用，也能通过 Node.js 跑在服务器上。

需要记住：

text
JavaScript = Web 世界最核心的编程语言之一

4. TypeScript 是什么？

TypeScript，简称 TS。

它可以理解成“更严格、更适合大型项目的 JavaScript”。

JavaScript 比较自由，但大型项目里容易出错。TypeScript 增加了类型系统。

举例：

ts
const age: number = 32

这表示：

text
age 必须是数字

如果写成：

ts
const age: number = "32"

TypeScript 会提示：这里不符合类型要求。

需要记住：

text
TypeScript = 带类型约束的 JavaScript，更适合团队项目和大型工程

5. Node.js 是什么？

浏览器能运行 JavaScript。 但是后端服务器原本不能直接像浏览器一样跑 JS。

Node.js 的作用就是让 JavaScript 可以在服务器、命令行和工具脚本里运行。

Node.js 官方定义为一个免费、开源、跨平台的 JavaScript runtime environment，可用于创建服务器、Web 应用、命令行工具和脚本。

需要记住：

text
Node.js = 让 JavaScript 跑在浏览器外面的运行环境

所以：

text
JavaScript / TypeScript = 语言
Node.js = 运行这种语言的环境

6. React 是什么？

React 是前端 UI 库。

它的核心思想是：

text
把界面拆成一个个组件，然后组合成页面

React 官方文档也强调，React 用 components 构建用户界面。

例如一个页面可以拆成：

text
Header
Sidebar
ChatWindow
InputBox
Button
Card

这些都是组件。

需要记住：

text
React = 用组件构建用户界面的前端库

7. Next.js 是什么？

Next.js 是基于 React 的全栈框架。

React 主要负责界面。 Next.js 在 React 之上增加了：

text
页面路由
服务端渲染
API Routes
部署优化
前后端一体能力

可以先粗略理解成：

text
React = 做界面
Next.js = 用 React 做完整 Web 应用的框架

8. Vite 是什么？

Vite 是前端开发和构建工具。

当前阶段很多原型项目如果是 Vite 项目，会有：

text
vite.config.ts
npm run dev
npm run build

只需记住：

text
Vite = 帮前端项目快速启动、开发、打包的工具

9. Python 是什么？

Python 是另一种编程语言。

在 AI 工程里很常见，因为大量 AI / 数据 / RAG / Agent 工具最早都在 Python 生态里。

需要记住：

text
Python = AI 后端、数据处理、RAG、Agent 编排里非常常用的语言

但这不代表所有 AI App 都必须用 Python。 很多 Web AI 应用也会用 TypeScript / Node / Next.js。

10. npm 是什么？

npm 是 JavaScript / Node 生态的依赖管理工具。

可以理解为：

text
项目需要用哪些外部工具包
npm 帮助学习者下载、安装、管理版本

例如：

bash
npm install

意思是：

text
根据 package.json，把这个项目需要的依赖装好

11. package.json 是什么？

package.json 是前端 / Node 项目里非常重要的文件。

它通常记录：

text
项目名称
依赖包
启动命令
构建命令
脚本命令

例如：

json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": {
    "react": "^19.0.0"
  }
}

只需看懂：

text
npm run dev    = 启动开发环境
npm run build  = 打包构建
dependencies  = 项目依赖

12. Git / GitHub 是什么？

Git 是版本控制工具。 GitHub 是代码托管和协作平台。

可以理解为：

text
Git = 本地记录代码每次变化
GitHub = 把代码放到云端，方便协作和回溯

后续使用 Codex / Claude Code 时，必须知道：

text
代码改了哪些文件？
有没有新建文件？
有没有删掉东西？
能不能回滚？

这些都和 Git / GitHub 有关。

14. 实战判断

后续看到项目目录时，先找这几个文件：

text
package.json      看项目命令和依赖
src/              看主要源码
app/ 或 pages/    看页面或路由
components/       看组件
api/              看接口
vite.config.ts    Vite 项目配置
next.config.js    Next.js 项目配置
.env              环境变量

如果看到：

text
package.json + vite.config.ts

大概率是 React / Vite 项目。

如果看到：

text
package.json + next.config.js + app/

大概率是 Next.js 项目。

如果看到：

text
requirements.txt / pyproject.toml + main.py

大概率是 Python 后端项目。
